# Homebrew tap for FxSound Mac

Install on an Apple Silicon Mac with Homebrew:

```sh
brew install --cask thanhpham1108/fxsound/fxsound-mac
```

Then open **FxSound Mac** from Applications and allow **System Audio Recording**.

The app supports macOS 14.2 or later. Homebrew itself currently supports macOS 15 or later; macOS 14 users can install the ZIP from the [FxSound Mac v0.1.0 release](https://github.com/thanhpham1108/fxsound-macos-port/releases/tag/v0.1.0).

Upgrade or remove it with:

```sh
brew upgrade --cask fxsound-mac
brew uninstall --cask fxsound-mac
```

This is a development preview. See the [main repository](https://github.com/thanhpham1108/fxsound-macos-port) for validation results and current limitations.
